# Lanefall

A single-player, portrait-mode card battler for phones: three lanes, simultaneous hidden planning, and lane combat
whose overflow damage hits the enemy hero. Installable, offline-capable web app.

See [`docs/spec.md`](docs/spec.md) for the full design and milestone plan, and [`CLAUDE.md`](CLAUDE.md) for commands.

```bash
pnpm install
pnpm dev
```
