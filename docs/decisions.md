# Decisions

Choices made where `docs/spec.md` is silent. Newest last.

| Date | Question | Decision |
| ---------- | --------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ | --------------------------------------------------------------------------------------- |
| 2026-11-20 | TypeScript version | Pin `~6.0` — typescript-eslint does not yet support TypeScript 7. |
| 2026-11-20 | GitHub Pages base path | Build reads `VITE_BASE` (default `/`); the deploy job sets `/<repo>/`. |
| 2026-11-20 | When does CI run, and when does it deploy? | Lint, typecheck, unit and e2e run on every push and PR; deploy to Pages only on push to `main` after checks pass. |
| 2026-11-20 | Determinism lint rule scope | Bans `Math.random`, `Date` and `performance` in `src/engine`, `src/run`, `src/ai`; also bans imports of React or `src/ui` there. |
| 2026-11-20 | Hand fan at narrow widths | Card spacing shrinks with viewport width (max 62 px) so 8 cards fit at 360 px with no overflow. |
| 2026-11-20 | Landscape threshold | Show "Rotate your phone" when landscape and height ≤ 500 px, so desktop browsers still show the game. |
| 2026-11-20 | PWA icons | Generated from `public/icon.svg` by `tools/render-icons.ts` and committed. |
| 2026-11-20 | `workbox-window` | Added as a dev dependency; `vite-plugin-pwa`'s register module imports it and the build fails without it. |
| 2026-11-20 | M1: how many lane effects? | 8 in M1 (Open Field, Forge, Chasm, Narrows, Bulwark, Sanctuary, Ashfield, Spring); the full 20 arrive in M5. |
| 2026-11-20 | Reserve: does old Reserve carry over? | Unspent mana and unspent Reserve together become next round's Reserve, capped at 2. Spells spend Reserve before mana. Mana for fizzled cards is still spent. |
| 2026-11-20 | Mulligan order | Replacement cards are drawn first, then the returned cards are shuffled into the deck. |
| 2026-11-20 | Drawing from an empty deck | Nothing happens (no fatigue damage). |
| 2026-11-20 | Planned unit's slot taken at reveal (e.g. by a summon) | It goes to the first free slot in that lane; if the lane is full it fizzles (mana spent, card discarded). |
| 2026-11-20 | When does Shift move? | The move is planned like a card (free) and happens in reveal order. If the destination has filled, nothing happens and Shift is not used up. |
| 2026-11-20 | Barrier in lane combat | A Barrier unit is assigned damage up to its remaining Health as normal; the Barrier absorbs all of it. |
| 2026-11-20 | Lifesteal amount | Heals by the sum of Power of Lifesteal units in that lane, once, if that lane dealt any hero damage this combat. |
| 2026-11-20 | Hero HP cap | Healing cannot raise a hero above starting HP. |
| 2026-11-20 | Deaths timing | Checked after each revealed card, after each lane's combat, and after End of Round; Last Breath effects resolve right after, repeating until stable. |
| 2026-11-20 | End of Round order | Units (lane L→R, initiative player first, play order): Growth, Regenerate, their End of Round effects; then lane effects; then Ephemeral units die; then temporary buffs expire. |
| 2026-11-20 | Win check timing | After combat, and again after End of Round (End of Round effects can damage heroes). If the match ends after combat, End of Round is skipped. |
| 2026-11-20 | Summoned units | Do not trigger On Reveal or Rally. Tokens are not added to the discard pile when they die. |
| 2026-11-20 | Card `unlock` field | `starter` (the 12 starting commons per faction) or `track` (placed on the unlock track in M6). |
| 2026-11-20 | AI planner signature | `plan(state, player, rng)` returns `{ actions, rng }` so the AI's RNG stream stays pure and serialisable. Easy AI lands early (M1) because the simulator needs a bot. |
| 2026-11-20 | Coverage gate | `pnpm coverage` enforces ≥90% statements, lines, functions and branches on `src/engine`. |
| 2026-11-20 | M2: which decks before M3's pre-built decks? | Each playable faction (Ember, Bastion) gets a 30-card starter deck: every card once, then commons to 30. The AI plays the other faction. |
| 2026-11-20 | Normal AI: what counts as a distinct play? | One action per card per lane (slot within a lane doesn't change the result). Plans are built breadth-first, keeping the best 200 by quick score (unit Power + Health, spell cost × 2.5) at each depth. |
| 2026-11-20 | Normal AI hidden information | Before planning, the opponent's planned cards are removed from the state; the simulation plays the candidate against an empty opponent plan. |
| 2026-11-20 | Normal AI mulligan | Replaces cards costing 5 or more. |
| 2026-11-20 | How the UI animates a round | The engine returns events; the UI steps a display-only view model through them with per-event durations (reveal ~500 ms, lane combat ~550 ms), then replaces it with the engine's resulting state. |
| 2026-11-20 | Tap vs long-press | Tapping a hand card or a board unit opens its full rules text (a long-press also works since it ends as a tap). Tapping a planned (ghost) unit or a queued spell chip takes it back. |
| 2026-11-20 | Drag offset | The dragged card is drawn 70 px above the finger and drop targets are tested at that point, so the thumb never hides the target. |
| 2026-11-20 | Test hooks | `?seed=N` fixes the match seed and `?speed=x` scales animation durations. Both are harmless in normal play. |
| 2026-11-20 | M3: starter collection | Exactly 12 commons per faction are `starter`; Bastion's Cathedral Guard and Call to Arms moved to the unlock track (uncommon) to match the spec. |
| 2026-11-20 | M3: pre-built decks "for the factions so far" | Three: Ember Blitz (Ember), Bastion Wall (Bastion), Sunforged Legion (Ember + Bastion). All use only starter cards. More arrive with each faction in M5. |
| 2026-11-20 | Locked cards in the collection | Shown greyed with "Locked · unlock track"; the exact level appears once the unlock track exists (M6). |
| 2026-11-20 | Incomplete decks | Not saved (the spec blocks saving until legal). The draft survives moving between screens while the app is open, and is lost on reload. |
| 2026-11-20 | Deck share code format | `LD1-` + base64url of (card index, count) byte pairs, indexed by position in the collectible card list. Card order in `cards.json` must only ever be appended to. Imported decks open in the builder so the player can name and save them. |
| 2026-11-20 | Save slot format | Each slot holds `{ seq, checksum, json }`; `seq` increases on every write and the higher valid one is current. Checksum is FNV-1a over the JSON. |
| 2026-11-20 | Save code format | `LS1.` + base64url(deflate-raw(JSON)) + `.` + FNV-1a checksum of the JSON. Importing migrates older schemas. Restoring asks for a second tap to confirm. |
| 2026-11-20 | Both slots corrupt | Show the damaged data for copying; "Start a new save" first copies it to a `save-broken-<time>` key, then writes a fresh profile. |
| 2026-11-20 | IndexedDB unavailable | Fall back to an in-memory save for the session and say so in Settings. |
| 2026-11-20 | Quick Play XP and stats | Recorded now (win 50 XP, loss or draw 20; played/won per deck id). Levels from XP arrive in M6. Leaving a match early records nothing. |
| 2026-11-20 | Quick Play opponent deck | A pre-built deck chosen by the match seed, different from yours when you play a pre-built deck. |
| 2026-11-20 | Quick Play mid-match saves | Not saved; the spec's End Turn autosave applies to runs (M4). |
| 2026-11-20 | Long-press in the deck builder | Tap adds a card; long-press opens its full text. In the collection, tap opens full text. |
| 2026-11-20 | How hero passives, relics and boss rules affect a match | One data mechanism: `MatchConfig.modifiers` per player (`heroHp`, `startReserve`, `startHand`, and `roundStart` primitives on chosen rounds, after the draw). Round-start effects can only use selectors that need no source unit or lane. |
| 2026-11-20 | Starting heroes before M5 adds factions | Pyra (Ember), Kael (Ember) and Aldric (Bastion). M5/M6 rebalance the roster to 2 heroes per faction. |
| 2026-11-20 | Map shape | 7 rows of 2–3 nodes, then the boss as an 8th row. Row 1 is always fights; row 7 is always rests. Other rows: Fight 55%, Rest/Shop/Treasure 15% each. Paths never cross and only lead to neighbouring columns. |
| 2026-11-20 | Run length in M4 | Act 1 only: beating the act 1 boss wins the run. Acts 2–3 and the second faction pick arrive in M5. |
| 2026-11-20 | Draws in run matches | A draw counts as a loss (costs a Heart, no reward). |
| 2026-11-20 | Losing to a boss with Hearts left | Rematch the boss (a new match seed). Losing a normal fight moves you on with no reward and no XP for that node. |
| 2026-11-20 | Rest before card upgrades exist | Rest offers only "Restore 1 Heart" (disabled at full Hearts) or move on; "Upgrade a card" comes with upgrades in M5. |
| 2026-11-20 | Economy | Start with 30 gold; fights give 15–25. Shop: 4 cards (common 25, uncommon 40, rare 60, legendary 80) and 2 relics (75); removing a card costs 40, once per shop. Empty treasure (all relics owned) gives 50 gold. |
| 2026-11-20 | Card rewards and shop pool | Owned cards (starter + unlocks, captured at run start) of the hero's faction, uniformly, 3 distinct per reward. |
| 2026-11-20 | Enemy AI in runs | Each enemy names its difficulty in `enemies.json`: act 1 fights are Easy, the boss is Normal. Boss rule hooks (`ai.seesPlan`) are passed to the planner. |
| 2026-11-20 | Run XP for a boss | The boss node gives 10 (node cleared) + 100 (boss beaten); the total doubles on a full win. XP is added when the run ends, including abandoned and lost runs. |
| 2026-11-20 | Abandoning | Allowed on any run screen except during a match (leave the match first). The match state is kept, so leaving a run match and coming back resumes it. |
| 2026-11-20 | Mid-match run saves | Saved after the match starts, after the mulligan and after every End Turn: `{ step, game, aiRng }`. Closing mid-turn loses only the cards planned this turn. |
| 2026-11-20 | M5: hard-to-hit drop targets | The drop point snaps to the nearest valid target within 44 px when it is not over one (gaps between slots, small unit tokens). While a spell is dragged, the card shrinks under the finger and the arrow locks onto the target it would hit. |
| 2026-11-20 | M5: spells on units planned this turn | Friendly and any-unit spells (Kindle, Blessing, …) may target a unit you planned earlier in the same turn: it reveals first and keeps its hand uid. Taking the unit back drops the spell. Enemy-unit spells still need a unit on the board. |
| 2026-11-20 | M5: "every card has a test that its effect resolves as its text says" | Rules text is generated from card data (`src/engine/text.ts`) and a test requires `cards.json` text to match. `tests/unit/cards.test.ts` then plays every card and its upgrade on a standard board and checks each effect's events in its trigger window. |
| 2026-11-20 | M5: card upgrades | The upgraded card is `<id>+`, named "Name+". Default: units +1 Power; spells +1 to every damage/heal/buff amount, or 1 less cost if they have none. A card's `upgrade` field overrides this. Tokens have no upgrade. |
| 2026-11-20 | M5: new cards | Tide, Grove and Dusk get 30 cards each, Ember and Bastion 10 more; each faction keeps 12 starter commons, about 10 spells and the spec's curve (within one card per cost). New tokens: Sapling (Grove), Shade (Dusk). |
| 2026-11-20 | M5: pre-built decks | One per faction pair (10); the mono-faction decks are gone. Each uses 5 starter commons per faction ×3. Sunforged Legion keeps its M3 list. |
| 2026-11-20 | M5: lane effects | 12 more (20 total) using the existing lane fields. "Both heroes" effects are two primitives, one per hero. |
| 2026-11-20 | M5: map nodes | Fight 40%, Event 20%, Elite 12%, Rest 10%, Shop 10%, Treasure 8%. Elites never appear in rows 1–2 of an act. |
| 2026-11-20 | M5: elites | Normal AI (Hard in act 3) with stronger decks and +5–8 hero HP. Reward: a random relic, a card choice and 15 extra gold. |
| 2026-11-20 | M5: events | Data in `events.json`: each choice has an optional gold/Heart cost and outcomes (gold, Heart, random card of at least a rarity, relic, upgrade or remove random cards). A Heart cost can never end the run, and every event has a free choice. |
| 2026-11-20 | M5: acts | Beating an act 1 or 2 boss gives 40–60 gold and a relic, then the next act's new map. A new act restores 1 Heart. After act 1, pick a second faction from the other four (the UI requires a pick). Act 3's boss wins the run. |
| 2026-11-20 | M5: bosses | 3 per act, one picked at random for each run's act; each has a rule shown before the fight, built from match modifiers or AI hooks. Act 3 bosses use Hard AI. |
| 2026-11-20 | M5: relics | 30 more (40 total) from the same modifiers, plus `run.hearts` (Fourth Heart: +1 Heart and +1 Heart limit). Relics have no rarity yet. |
| 2026-11-20 | M5: Hard AI | Normal's 20 best plans, each scored against 30 sampled opponent plans (opponent hand guessed from their unplayed cards, one of their 6 best plays picked at random). The work is fixed, so it is deterministic; the UI passes a clock and Hard returns the best plan so far after 500 ms. Full search measures well under 500 ms (CI benchmark in `tests/sim/hard.test.ts`). |
| 2026-11-20 | M5: saves | Profile schema v3. A v2 run in progress is dropped on migration: its choices replay differently with the new map and content. |
| 2026-11-20 | M5: bot run test time | The 500 bot runs now go up to 3 acts; the test timeout is 3 minutes. |
| 2026-11-20 | M6: slot damage order | Lane damage follows slot position (front-left, front-right, back-left, back-right = slots 0-3), after Guard. Empty slots are skipped and gaps never close, so units keep their slot until they die or shift. `playOrder` still orders reveals and End of Round triggers. |
| 2026-11-20 | M6: combat event order | `LaneCombat` carries each side's hit breakdown and an `order`: the initiative player's strike (unit hits, hero damage, Lifesteal) is emitted and applied first. Assignments come from the pre-combat board, so this is presentational; the one effect is that a Lifesteal heal can now be capped by the other side's hero damage in a different order. |
| 2026-11-20 | M6: combat forecast | `previewCombat` places the player's planned units at printed stats and runs the normal assignment. It ignores On Reveal effects (Rally included), spells, shifts and the opponent's plan, so it is a forecast of the board as it stands, not a promise. |
| 2026-11-20 | M6: AI slots | Planners still dedupe plays by (card, lane). Once a plan is chosen, its new units are re-slotted front-first by toughness: Guard, then Barrier, then higher Health, then lower Power. Easy stays random. |
| 2026-11-20 | M6: unlock track | `src/content/unlocks.json`: one bundle per level 2-30 (29). 7 hero bundles (the hero plus 3 track cards of its faction), 18 card bundles (3-4 track cards of one faction) and 4 relic bundles (3 relics). Every track card (90 non-token) and new hero appears once. Heroes are at levels 3, 6, 9, 13, 17, 21, 25; relics at 8, 15, 22, 28; within a faction rarer cards come later. The spec's "3-4 cards" is kept: 90 cards cannot split into 4s, so three bundles hold 3 (two Ember, one Bastion). |
| 2026-11-20 | M6: locked relics | 12 of the 40 relics are locked behind the track (War Horn, Aegis, Venom Vial; Mana Crystal, Hourglass, Vampiric Fang; Giant Tooth, Storm Bottle, Phoenix Feather; Titan Belt, Fourth Heart, Bloodstone). The relic pool is every relic not on the track plus the unlocked ones, so a new profile has 28. No `unlock` field: the track is the only source. |
| 2026-11-20 | M6: new heroes | Brenna (Bastion), Marin and Corin (Tide), Sylva and Oren (Grove), Vesper and Morrow (Dusk), each with a passive built from existing match modifiers and a 12-card deck of that faction's starter commons. Hero `unlock` is `track`. |
| 2026-11-20 | M6: level and unlock bookkeeping | `profile.level` and `profile.unlocks` are always derived from `xp` (`withXp`/`grantXp` in `src/run/meta.ts`); `unlocks` lists every unlocked id (cards, heroes, relics). Owned cards, heroes and relics are derived from the level. |
| 2026-11-20 | M6: XP curve | Level n needs 100 + 50n XP to reach n + 1, so level 2 is at 150 XP and level 30 at 24,650 XP. XP past the cap still counts but changes nothing. |
| 2026-11-20 | M6: Ascension rules | Cumulative: level n applies rules 1..n. 1 elites +2 HP; 2 shops +25% (relic discount first, then rounded up; also the card removal price); 3 start with 15 less gold; 4 normal fights +3 HP; 5 gold from fights, elites and bosses -25% (rounded down, after relic bonuses); 6 bosses +5 HP; 7 act 1 enemies on Easy AI use Normal; 8 a rest cannot restore a Heart (leave or upgrade); 9 card rewards offer 2 cards, relics still add; 10 start with 2 Hearts (limit stays 3). Extra HP is an enemy `heroHp` match modifier. Data in `ascension.json`. |
| 2026-11-20 | M6: Ascension unlocking | `profile.ascension` is `{ best, unlocked }`. `unlocked` is 0 until the first full run win; a full win at level n equal to `unlocked` opens min(n + 1, 10); `best` is the highest level won (`recordRunResult`). The run config records `ascension` and the `relics` pool at run start, like `pool`. |
| 2026-11-20 | M6: saves v4 | Migration v3 to v4 recomputes the level and unlocks from XP, sets Ascension `unlocked` to min(best + 1, 10) if any Ascension was won or any run won (else 0), and gives a run in progress Ascension 0 and all 40 relics so it replays unchanged. |
| 2026-11-20 | M6: simulator | `pnpm sim:run [n] [easy\|normal\|hard] [ascension]` uses a fully unlocked profile (every card, relic and all 10 heroes). |
| 2026-11-20 | M7: saves v5 | Settings gain `sound` and `haptics` (both on by default); the profile gains `tutorialDone` and `iosTipSeen` (both false by default). Migration v4 to v5 turns Sound and Haptics on, sets `tutorialDone` to true if the profile has any XP or any Quick Play or run results (the player has already played), and `iosTipSeen` to false. |
| 2026-11-20 | M7: sound synthesis | Sounds are short Web Audio oscillator tones (no audio files, no dependency). The AudioContext is created and resumed on the first pointer or key event, since browsers refuse audio before a gesture; with no AudioContext, or a suspended one, a sound does nothing. The same kind of sound is throttled to one per 40 ms so a burst of hits does not stack. Kinds: tap, play, reveal, hit, heroHit, death, win, lose, levelUp. Draws play no result sound. |
| 2026-11-20 | M7: haptic patterns | `navigator.vibrate` where it exists, only when the Haptics setting is on, in try/catch. Patterns in ms: tap 8, card played 15, unit hit 10, hero hit 30-40-30, win 20-60-20-60-40, loss 80-60-120. Same 40 ms throttle per kind. iOS has no vibrate API, so it does nothing there. |
| 2026-11-20 | M7: iOS tip detection | Shown on the menu when the user agent is iPhone, iPad or iPod, or a Macintosh agent with more than one touch point (iPadOS), is not Chrome, Firefox, Edge or Opera on iOS, is not standalone (`navigator.standalone` or `display-mode: standalone`), and `iosTipSeen` is false. "Got it" sets `iosTipSeen` and autosaves. Logic is the pure `shouldShowIosTip` in `src/ui/ios.ts`. |
| 2026-11-20 | M7: motion scale and Reduce motion | The effective duration scale is URL `?speed` x (Fast animations ? 0.5 : 1), from `src/ui/motion.ts`; every JS-driven duration uses it. Reduce motion (the setting or the system preference) replaces movement, scaling, flips and rotation with a 120 ms opacity fade, and toggles a `reduce-motion` class on the root element so CSS can drop movement and keyframes too. The reveal flip is 250 ms; the CardRevealed event still holds 500 ms so the card stays readable. |
| 2026-11-20 | M7: tutorial match | The tutorial is a scripted 3-round Ember vs Bastion match (`src/content/tutorial.json`, schema and helpers in `src/run/tutorial.ts`): fixed seed, 7-card decks that are fully drawn by round 3 (so the cards each step needs are always in hand), fixed lane effects (Forge, Open Field, Open Field) and the opponent hero on 10 HP through the `heroHp` match modifier. The seed was chosen by scanning seeds for one whose opening hand holds both Spark Imps, Kindle and Fireball; `tests/unit/tutorial.test.ts` follows the script with the engine API and checks the player wins in round 3. It gives no XP or reward. |
| 2026-11-20 | M7: tutorial mulligan and opponent | Both mulligans are skipped (hands are kept automatically). The opponent plays scripted units (card id, lane, slot per round, resolved to hand uids) through `applyAction` instead of the AI, so the engine still validates every move. |
| 2026-11-20 | M7: tutorial gating | `mode: 'tutorial'` in the match store holds a coach step index. A `play` or `cast` step accepts only that card (either copy) on that slot or target; the hand offers only that play and dims every other card; End Turn works only on an `endTurn` step; taking back a planned card is off. `info` steps wait for Next, and the `watch` step ends when the round's playback finishes. The match is never autosaved. |
| 2026-11-20 | M7: tutorial completion and entry | Winning shows "Tutorial complete" and Back to menu sets `profile.tutorialDone` (autosaved). Leaving mid-tutorial returns to the menu without setting it. The menu has a Tutorial button for replays, and a fresh profile (tutorial not done, no XP, no results, no run) also sees an inline "New here? Play the tutorial" prompt with Play and Skip; Skip sets `tutorialDone`. The prompt does not block the other buttons. |
| 2026-11-20 | M7: tutorial coach banner | The coach banner sits over the opponent's back row (slots 3 and 4), which the script never uses, so it covers neither the hand, End Turn nor any unit. Its text is at most 2 lines at 360 px wide; it fades in (no movement under Reduce motion) and its duration follows the motion scale. The required slot, planned unit or board gets a pulsing outline, and the required hand card pulses. |
| 2026-11-20 | M8: mutual KO | Rule change: when both heroes are on 0 HP or less at a win check, the hero with more HP left wins; equal HP is a draw (as after round 8). Before this, 12% of Normal-vs-Normal matches were draws, and the balance target counts a draw as a loss, so 45–55% per faction was out of reach. Draws fell to about 3%. |
| 2026-11-20 | M8: balance win rate | A draw counts as a loss for both sides in the balance report's win rates. |
