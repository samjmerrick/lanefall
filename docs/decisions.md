# Decisions

Choices made where `docs/spec.md` is silent. Newest last.

| Date       | Question                                                | Decision                                                                                                                                                                                                                                   |
| ---------- | ------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 2026-11-20 | TypeScript version                                      | Pin `~6.0` — typescript-eslint does not yet support TypeScript 7.                                                                                                                                                                          |
| 2026-11-20 | GitHub Pages base path                                  | Build reads `VITE_BASE` (default `/`); the deploy job sets `/<repo>/`.                                                                                                                                                                     |
| 2026-11-20 | When does CI run, and when does it deploy?              | Lint, typecheck, unit and e2e run on every push and PR; deploy to Pages only on push to `main` after checks pass.                                                                                                                          |
| 2026-11-20 | Determinism lint rule scope                             | Bans `Math.random`, `Date` and `performance` in `src/engine`, `src/run`, `src/ai`; also bans imports of React or `src/ui` there.                                                                                                           |
| 2026-11-20 | Hand fan at narrow widths                               | Card spacing shrinks with viewport width (max 62 px) so 8 cards fit at 360 px with no overflow.                                                                                                                                            |
| 2026-11-20 | Landscape threshold                                     | Show "Rotate your phone" when landscape and height ≤ 500 px, so desktop browsers still show the game.                                                                                                                                      |
| 2026-11-20 | PWA icons                                               | Generated from `public/icon.svg` by `tools/render-icons.ts` and committed.                                                                                                                                                                 |
| 2026-11-20 | `workbox-window`                                        | Added as a dev dependency; `vite-plugin-pwa`'s register module imports it and the build fails without it.                                                                                                                                  |
| 2026-11-20 | M1: how many lane effects?                              | 8 in M1 (Open Field, Forge, Chasm, Narrows, Bulwark, Sanctuary, Ashfield, Spring); the full 20 arrive in M5.                                                                                                                               |
| 2026-11-20 | Reserve: does old Reserve carry over?                   | Unspent mana and unspent Reserve together become next round's Reserve, capped at 2. Spells spend Reserve before mana. Mana for fizzled cards is still spent.                                                                               |
| 2026-11-20 | Mulligan order                                          | Replacement cards are drawn first, then the returned cards are shuffled into the deck.                                                                                                                                                     |
| 2026-11-20 | Drawing from an empty deck                              | Nothing happens (no fatigue damage).                                                                                                                                                                                                       |
| 2026-11-20 | Planned unit's slot taken at reveal (e.g. by a summon)  | It goes to the first free slot in that lane; if the lane is full it fizzles (mana spent, card discarded).                                                                                                                                  |
| 2026-11-20 | When does Shift move?                                   | The move is planned like a card (free) and happens in reveal order. If the destination has filled, nothing happens and Shift is not used up.                                                                                               |
| 2026-11-20 | Barrier in lane combat                                  | A Barrier unit is assigned damage up to its remaining Health as normal; the Barrier absorbs all of it.                                                                                                                                     |
| 2026-11-20 | Lifesteal amount                                        | Heals by the sum of Power of Lifesteal units in that lane, once, if that lane dealt any hero damage this combat.                                                                                                                           |
| 2026-11-20 | Hero HP cap                                             | Healing cannot raise a hero above starting HP.                                                                                                                                                                                             |
| 2026-11-20 | Deaths timing                                           | Checked after each revealed card, after each lane's combat, and after End of Round; Last Breath effects resolve right after, repeating until stable.                                                                                       |
| 2026-11-20 | End of Round order                                      | Units (lane L→R, initiative player first, play order): Growth, Regenerate, their End of Round effects; then lane effects; then Ephemeral units die; then temporary buffs expire.                                                           |
| 2026-11-20 | Win check timing                                        | After combat, and again after End of Round (End of Round effects can damage heroes). If the match ends after combat, End of Round is skipped.                                                                                              |
| 2026-11-20 | Summoned units                                          | Do not trigger On Reveal or Rally. Tokens are not added to the discard pile when they die.                                                                                                                                                 |
| 2026-11-20 | Card `unlock` field                                     | `starter` (the 12 starting commons per faction) or `track` (placed on the unlock track in M6).                                                                                                                                             |
| 2026-11-20 | AI planner signature                                    | `plan(state, player, rng)` returns `{ actions, rng }` so the AI's RNG stream stays pure and serialisable. Easy AI lands early (M1) because the simulator needs a bot.                                                                      |
| 2026-11-20 | Coverage gate                                           | `pnpm coverage` enforces ≥90% statements, lines, functions and branches on `src/engine`.                                                                                                                                                   |
| 2026-11-20 | M2: which decks before M3's pre-built decks?            | Each playable faction (Ember, Bastion) gets a 30-card starter deck: every card once, then commons to 30. The AI plays the other faction.                                                                                                   |
| 2026-11-20 | Normal AI: what counts as a distinct play?              | One action per card per lane (slot within a lane doesn't change the result). Plans are built breadth-first, keeping the best 200 by quick score (unit Power + Health, spell cost × 2.5) at each depth.                                     |
| 2026-11-20 | Normal AI hidden information                            | Before planning, the opponent's planned cards are removed from the state; the simulation plays the candidate against an empty opponent plan.                                                                                               |
| 2026-11-20 | Normal AI mulligan                                      | Replaces cards costing 5 or more.                                                                                                                                                                                                          |
| 2026-11-20 | How the UI animates a round                             | The engine returns events; the UI steps a display-only view model through them with per-event durations (reveal ~500 ms, lane combat ~550 ms), then replaces it with the engine's resulting state.                                         |
| 2026-11-20 | Tap vs long-press                                       | Tapping a hand card or a board unit opens its full rules text (a long-press also works since it ends as a tap). Tapping a planned (ghost) unit or a queued spell chip takes it back.                                                       |
| 2026-11-20 | Drag offset                                             | The dragged card is drawn 70 px above the finger and drop targets are tested at that point, so the thumb never hides the target.                                                                                                           |
| 2026-11-20 | Test hooks                                              | `?seed=N` fixes the match seed and `?speed=x` scales animation durations. Both are harmless in normal play.                                                                                                                                |
| 2026-11-20 | M3: starter collection                                  | Exactly 12 commons per faction are `starter`; Bastion's Cathedral Guard and Call to Arms moved to the unlock track (uncommon) to match the spec.                                                                                           |
| 2026-11-20 | M3: pre-built decks "for the factions so far"           | Three: Ember Blitz (Ember), Bastion Wall (Bastion), Sunforged Legion (Ember + Bastion). All use only starter cards. More arrive with each faction in M5.                                                                                   |
| 2026-11-20 | Locked cards in the collection                          | Shown greyed with "Locked · unlock track"; the exact level appears once the unlock track exists (M6).                                                                                                                                      |
| 2026-11-20 | Incomplete decks                                        | Not saved (the spec blocks saving until legal). The draft survives moving between screens while the app is open, and is lost on reload.                                                                                                    |
| 2026-11-20 | Deck share code format                                  | `LD1-` + base64url of (card index, count) byte pairs, indexed by position in the collectible card list. Card order in `cards.json` must only ever be appended to. Imported decks open in the builder so the player can name and save them. |
| 2026-11-20 | Save slot format                                        | Each slot holds `{ seq, checksum, json }`; `seq` increases on every write and the higher valid one is current. Checksum is FNV-1a over the JSON.                                                                                           |
| 2026-11-20 | Save code format                                        | `LS1.` + base64url(deflate-raw(JSON)) + `.` + FNV-1a checksum of the JSON. Importing migrates older schemas. Restoring asks for a second tap to confirm.                                                                                   |
| 2026-11-20 | Both slots corrupt                                      | Show the damaged data for copying; "Start a new save" first copies it to a `save-broken-<time>` key, then writes a fresh profile.                                                                                                          |
| 2026-11-20 | IndexedDB unavailable                                   | Fall back to an in-memory save for the session and say so in Settings.                                                                                                                                                                     |
| 2026-11-20 | Quick Play XP and stats                                 | Recorded now (win 50 XP, loss or draw 20; played/won per deck id). Levels from XP arrive in M6. Leaving a match early records nothing.                                                                                                     |
| 2026-11-20 | Quick Play opponent deck                                | A pre-built deck chosen by the match seed, different from yours when you play a pre-built deck.                                                                                                                                            |
| 2026-11-20 | Quick Play mid-match saves                              | Not saved; the spec's End Turn autosave applies to runs (M4).                                                                                                                                                                              |
| 2026-11-20 | Long-press in the deck builder                          | Tap adds a card; long-press opens its full text. In the collection, tap opens full text.                                                                                                                                                   |
| 2026-11-20 | How hero passives, relics and boss rules affect a match | One data mechanism: `MatchConfig.modifiers` per player (`heroHp`, `startReserve`, `startHand`, and `roundStart` primitives on chosen rounds, after the draw). Round-start effects can only use selectors that need no source unit or lane. |
| 2026-11-20 | Starting heroes before M5 adds factions                 | Pyra (Ember), Kael (Ember) and Aldric (Bastion). M5/M6 rebalance the roster to 2 heroes per faction.                                                                                                                                       |
| 2026-11-20 | Map shape                                               | 7 rows of 2–3 nodes, then the boss as an 8th row. Row 1 is always fights; row 7 is always rests. Other rows: Fight 55%, Rest/Shop/Treasure 15% each. Paths never cross and only lead to neighbouring columns.                              |
| 2026-11-20 | Run length in M4                                        | Act 1 only: beating the act 1 boss wins the run. Acts 2–3 and the second faction pick arrive in M5.                                                                                                                                        |
| 2026-11-20 | Draws in run matches                                    | A draw counts as a loss (costs a Heart, no reward).                                                                                                                                                                                        |
| 2026-11-20 | Losing to a boss with Hearts left                       | Rematch the boss (a new match seed). Losing a normal fight moves you on with no reward and no XP for that node.                                                                                                                            |
| 2026-11-20 | Rest before card upgrades exist                         | Rest offers only "Restore 1 Heart" (disabled at full Hearts) or move on; "Upgrade a card" comes with upgrades in M5.                                                                                                                       |
| 2026-11-20 | Economy                                                 | Start with 30 gold; fights give 15–25. Shop: 4 cards (common 25, uncommon 40, rare 60, legendary 80) and 2 relics (75); removing a card costs 40, once per shop. Empty treasure (all relics owned) gives 50 gold.                          |
| 2026-11-20 | Card rewards and shop pool                              | Owned cards (starter + unlocks, captured at run start) of the hero's faction, uniformly, 3 distinct per reward.                                                                                                                            |
| 2026-11-20 | Enemy AI in runs                                        | Each enemy names its difficulty in `enemies.json`: act 1 fights are Easy, the boss is Normal. Boss rule hooks (`ai.seesPlan`) are passed to the planner.                                                                                   |
| 2026-11-20 | Run XP for a boss                                       | The boss node gives 10 (node cleared) + 100 (boss beaten); the total doubles on a full win. XP is added when the run ends, including abandoned and lost runs.                                                                              |
| 2026-11-20 | Abandoning                                              | Allowed on any run screen except during a match (leave the match first). The match state is kept, so leaving a run match and coming back resumes it.                                                                                       |
| 2026-11-20 | Mid-match run saves                                     | Saved after the match starts, after the mulligan and after every End Turn: `{ step, game, aiRng }`. Closing mid-turn loses only the cards planned this turn.                                                                               |
